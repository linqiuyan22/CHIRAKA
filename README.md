# CHIRAKA · Vice Unity

西海岸落日霓虹基调的城市档案、街头论坛与黑胶电台站点。

## 模块结构

- **00 城市首页 (`index.html`)**：落日天际线主视觉与右侧交互式红线调查板，支持切换四大档案卷宗预览并直达对应分卷。
- **01 角色档案 (`characters.html` / `character.html`)**：支持按核心角色与配角筛选；独立卷宗页包含基础档案（姓名、别称、性别、生日、星座、年龄、身高、身份、所属）、人物设定摘要、外观与服装设定插图集、多章节角色故事线、跨模块联动索引及红线关系调查板。
- **02 城市新闻与街头论坛 (`news.html` / `article.html`)**：融合「官方新闻报道 (City Desk)」与「街头匿名论坛 (Night BBS)」，支持角色关联标签、热度与点赞统计，以及详情页内的多楼层市民/角色跟帖盖楼互动。
- **03 插画画廊 (`gallery.html`)**：按角色立绘、服装设定、群像与漫画分镜分类展示，灯箱内呈现高清原图、关联角色档案跳转与画面背后的故事注记，并与角色卷宗双向同步。
- **04 城市电台 (`radio.html`)**：三栏式黑胶唱机工作台，支持多频段电台切换、曲目检索、红心收藏、合成器背景音及角色印象曲联动。

## 访客模式与管理员模式

站点内置双模式访问控制（点击顶部导航栏右侧通行证按钮切换）：

- **访客模式 (`GUEST`)**：默认只读浏览视图，自动隐藏所有编辑控件，提供完整的档案查阅、论坛跟帖与电台播放体验。
- **管理员模式 (`ADMIN`)**：验证管理员口令（默认口令：`chiraka888`，可在「数据接口与备份」中修改）后开启顶部管理工作台，支持：
  - 直接点击页面任意封面图/拍立得框上的 `🖼 更换封面图`、卡片右上角的 `✎ 编辑` 或高亮的 `待补充` 字段进行在线编辑与本地图片上传。
  - 通过顶部 `📋 待补充项` 清单查看全站尚未填写的字段并一键跳转补齐。
  - 随时新增或删除角色卷宗、新闻/论坛帖、画廊分镜、电台频段与电台歌曲。

## 数据与框架分离架构及部署说明

站点采用**前端框架代码与动态业务数据分离**的设计：

- **框架层**：`*.html`、`styles*.css`、`app.js`、`data.js`（仅作接口配置与初始结构回退）。
- **数据层**：`data/content-data.json`（存放所有角色、新闻论坛、画廊、电台频段与歌曲数据）。
- **联网部署**：
  1. 在项目根目录运行 `node server.js`（零第三方依赖，默认监听 `3000` 端口，可通过环境变量 `PORT` 指定端口）。
  2. 服务端会自动托管静态页面，并提供 `GET /api/content` 与 `POST /api/content` 读写接口。
  3. 管理员在网页端保存任何修改时，数据会自动同步写入服务器上的 `data/content-data.json`，所有访客刷新即可看到最新内容。
